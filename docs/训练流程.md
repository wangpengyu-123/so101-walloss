# 训练流程（数据 → 模型 → 部署）

云端全链路。本仓库 `wallx/`、`configs/`、`scripts/`、`patches/` 就是完整复现材料。

## 一、数据录制（真机）

用 lerobot fork 录 v2.1 数据集。命令见 [数据录制协议.md](数据录制协议.md)。要点：

- 双相机：global（ASC60C，/dev/video10）+ wrist（W19）
- `--dataset.fps=12`（训练帧率）
- 相机 key 录出来是 `observation.images.global` / `observation.images.wrist`（**无 `.rgb` 后缀**）

## 二、后处理（严格照 wall-x 开源流程）

**不需要 unify_camera_keys**（那是为「真机↔仿真合并」做 key 对齐的；只训真机直接喂原始数据）。

算 norm_stats（6 维）：

```bash
python scripts/compute_norm_stats.py \
  --data_root <数据集root> \
  --output_path configs/norm_stats_round4.json
```

（自包含脚本，只读 parquet 的 state/action 列，输出 `{"norm_stats":{"observation.state":{...},"action":{...}}}` 6 维 mean/std/q01/q99）

## 三、训练（LoRA 微调）

config：`configs/config_full_v2_round4.yml`（关键字段）：

```yaml
task:
  dof_config: {so101_joint_pos: 6, action_padding: 20}   # 6 维关节 + 补 20 → 26
  agent_pos_config: {so101_joint_pos: 6, action_padding: 20}
  action_horizon: 32
data:
  lerobot_config: {repo_id: so101_table_pick_place, root: <数据集>}
  key_mappings:
    camera: {observation.images.global: global_view, observation.images.wrist: wrist_view}  # 无 .rgb
model:
  use_lora: true, lora_r: 16, lora_alpha: 32
  lora_target_modules: [qkv_proj_experts.0, qkv_proj_experts.1]
  lora_action_head_target_modules: [w1, w2, w3, action_proj_back]   # 动作头也 LoRA
  full_param_train_keywords: [propri_proj]                          # 状态投影全参
hyperparams.scheduler.num_training_steps: 30001
```

启动（云端）：

```bash
torchrun --nproc_per_node=1 wall_x/trainer/fsdp_trainer/train_fsdp.py --config configs/config_full_v2_round4.yml --log_to_file
```

- 单步 ~1.8s（4090），30001 步 ≈ 15h；**实际 ~5000 步已收敛**（wrist bias 平台化，后续加训无效）
- checkpoint 153 key = 144 qkv LoRA + 8 动作头 LoRA + 1 propri_proj（`save_interval=5000` 存 step checkpoint）

## 四、合并（LoRA → 完整模型）

```bash
torchrun --nproc_per_node=1 --master_port=<空闲端口> scripts/merge_v2.py \
  --train-config configs/config_full_v2_round4.yml \
  --checkpoint <output>/<N>_5000 \
  --output <merged_dir> \
  --wallx-src wallx
```

- 必须用 `merge_v2.py`（带防丢断言），**不能**用 peft `merge_and_unload`（会丢动作头全参更新，round1 的坑）
- 产物 843 tensors bf16（8.4G），含动作头 + propri_proj，无 lora 残留

## 五、serving + 开环评估

见 [云端部署.md](云端部署.md)。评估用 `scripts/eval_openloop4.py`，重点看 wrist_flex bias 是否塌陷。

## 六、复现检查清单

1. 数据 QA：肘跨集 std ≥ 10、夹爪覆盖开合、无 NaN（`qa_joint_variance.py` 思路）
2. smoke：先 `num_training_steps=20` 跑通（config/数据/模型/LoRA/153key checkpoint 全绿）
3. 5000 步早停评估：wrist bias 正常再决定是否跑满
4. resume：从 step checkpoint 续训后，loss 应 ≈ 暂停前（差一个量级 = resume bug）
