# 常见问题（FAQ）

## 真机/推理

### 1. `Connection refused` 连不上 serving
SSH 隧道掉了。重跑隧道命令，或检查 master 连接（`ssh -O check <别名>`）。**ControlMaster 换新 master 时旧的端口转发会丢**，重新 `ssh -O forward -L 32195:localhost:32195 <别名>`。

### 2. `/dev/video10 无新帧` / 相机链死
ascamera 节点 + 桥接进程掉线或没订阅。重启：

```bash
pkill -f ascamera; pkill -f ros2_camera_bridge
bash camera/run_ascamera_node.sh &
source /opt/ros/humble/setup.bash && python3 camera/ros2_camera_bridge.py &
```

### 3. ascamera 日志「start streaming 后立刻 stop streaming」
**没有订阅者时的正常表现**。桥接进程（订阅者）连上后相机自动恢复推流。别被这个吓到。

### 4. 夹爪报 `Missing motor IDs: 6`
从臂重新上电。

### 5. 串口设备为空 / 编号互换
USB 没插好或插拔后编号漂移。`ls /dev/serial/by-id/` 看 `...72`（主臂）/`...73`（从臂），以 by-id 为准，客户端 `--port` 按实际改。

### 6. 动作一顿一顿 / 太快
调 `--execute-interval`。默认 0.083（12fps 训练帧率）；轻柔用 0.15；还快就 0.18。

### 7. 夹爪收到负值
dry-run 打印的是**原始模型输出**（未套偏差补偿+钳位）。真机 `--execute` 路径会先偏差补偿再钳位 [0,100]，不会发负值。

## 训练

### 8. 官方 compute_norm_stats.py 报 `No module named 'numba'`
numba 只在 `_relative` 旋转键才用，我们 dof_config 无此键。用自包含的 `scripts/compute_norm_stats.py`（输出与官方逐字一致），或 `pip install numba`。

### 9. 要不要 unify_camera_keys（加 `.rgb` 后缀）
**不要**。那只为「真机 v2.1（无后缀）↔ 仿真 v3（带后缀）」合并对齐；只训真机直接喂原始数据，config key_mappings 写无后缀键即可。

### 10. serving 报 `follow_pos expects 7 dims`
没打 `so101_joint_pos` 的 3 处注册 patch（见 docs/云端部署.md）。本仓库 `wallx/` 已打；换干净 wall-x 需重打 `patches/patch_serving_so101.py`。

### 11. serving 启动就崩 / 第一帧崩
flash_attn 坏。加 `WALLX_VISION_ATTN_IMPLEMENTATION=sdpa`。

### 12. resume 后 loss 跳一个量级（如 0.02 → 0.5）
resume bug：动作头 base 没加载（随机初始化）。`wallx/` 已打 `patches/patch_resume_fix.py`。**续训后第一件事对比 loss 是否 ≈ 暂停前**。

### 13. 磁盘满（`No space left on device`）
删旧产物：round2 的 merged/checkpoint、旧的 smoke 合并产物、epoch checkpoint（保留 step checkpoint）。合并 8.4G + 训练 output ~2G 需要 ~11G 空闲。

### 14. 训练 5000 步后 wrist bias 不降（平台化）
**这是收敛，不是 bug**。round3 就观察到 wrist bias 5000→30000 步平台化；round4 修好数据后 bias 停在小值（+8°），继续加训无效。5000 步早停评估是关键检查点。

## 数据质量

### 15. 模型腕关节塌陷（输出锚死一个值）
根因 = **数据里该关节跨集不一致**（round3 腕集内静态但跨集跨度 129° → 模型回归错误均值）。修法：固定朝向任务，让腕跨集一致（跨度 35° 内）。判断用「集内/跨集方差比」。
