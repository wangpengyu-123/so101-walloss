# 架构总览

本项目分两条链路：**推理链路**（真机跑模型）和 **训练链路**（数据→模型）。本文讲清各组件怎么衔接。

## 一、推理链路（真机）

```
[本地真机]                                            [云端 AutoDL]
 ASC60C 相机 ──ascamera节点──► ROS2 话题
                              └─ros2_camera_bridge.py─► /dev/video10 ──┐
 W19 腕相机 (/dev/v4l/by-id/...W19...) ────────────────────────────────┤
 SO-ARM101 从臂 (/dev/serial/by-id/...73) ──串口读写 6关节+夹爪────────┤
                                                                      ▼
                                              client/wallx_realtime_client.py
                                                                      │ 相机帧(base64) + 6关节状态
                                                                      │ msgpack, WebSocket
                                                                      ▼
                                              SSH 隧道 :32195 ──► wall-x serving
                                                                      │ round4 模型推理
                                                                      ▼
                                              ◄─── 动作 [32,26] 取前6维 ───┘
                                              写回从臂舵机（--execute 时）
```

**四个衔接点**（对应文档）：

| 衔接 | 载体 | 协议/格式 | 文档 |
|---|---|---|---|
| 相机 → 客户端 | ROS2 话题 → /dev/video10 | bgr8 → RGB24 JPEG base64 | [真机部署.md](真机部署.md) |
| 机械臂 → 客户端 | USB 串口 | Feetech 舵机协议（0..4095 ↔ 归一化） | [真机部署.md](真机部署.md) |
| 客户端 → 云端 serving | SSH 隧道 :32195 | WebSocket + msgpack | [云端部署.md](云端部署.md) |
| serving → 模型 | 进程内 | Qwen2.5-VL 前向 | [训练流程.md](训练流程.md) |

## 二、训练链路（数据→模型）

```
录制(lerobot v2.1) → compute_norm_stats(6维 q01/q99) → train_fsdp(LoRA 30001步)
   → checkpoint(153 key: 144 qkv + 8 动作头 + 1 propri_proj) → merge_v2(防丢断言)
   → merged 模型(843 tensors) → serving(sdpa + norm-key) → 开环评估(eval_openloop4)
```

详见 [训练流程.md](训练流程.md)。

## 三、单位约定（重要，别混）

| 层 | 单位 |
|---|---|
| 模型/训练数据 | lerobot 归一化：关节 ±100（量程百分比）、夹爪 0..100 |
| 舵机总线 | 原始编码 0..4095 |
| 换算 | 由 `FeetechMotorsBus` 用标定文件 `range_min/range_max` 自动完成 |

**交互单位 = 归一化单位**（不是角度、不是原始编码）。这是从代码+数据实测确认的，见客户端 docstring。

## 四、关键约定

- **关节顺序**：`shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll, gripper`（6 维，`elbow_flex` 不是 `elbow`）
- **动作维度**：模型输出 [32, 26]，前 6 维 = 6 关节，后 20 维 = `action_padding` 恒 0
- **相机 key**：训练数据 v2.1 用 `observation.images.global` / `observation.images.wrist`（**无 `.rgb` 后缀**），config 的 key_mappings 映射到 `global_view` / `wrist_view`
- **norm-key**：`so101_table_pick_place`（serving 与训练必须一致）
- **推理**：`WALLX_VISION_ATTN_IMPLEMENTATION=sdpa`（flash_attn 在部署环境不可用）
