# 真机部署（相机链 + 机械臂 + 客户端）

本地真机三样硬件：ASC60C 相机（global）、W19 腕相机（wrist）、SO-ARM101 从臂。都接好后跑客户端。

## 一、相机链（global 画面 → /dev/video10）

ASC60C 不是 UVC 相机，要走 ROS2 链：

```
ASC60C → ascamera_node（ros2 包）→ ROS2 话题 /ascamera/camera_publisher/rgb0/image
       → ros2_camera_bridge.py → v4l2loopback /dev/video10 → 客户端读帧
```

**启动**（两个进程，都在后台）：

```bash
# 终端1：ascamera 节点
bash camera/run_ascamera_node.sh

# 终端2：桥接（订阅话题 → 写 /dev/video10）
source /opt/ros/humble/setup.bash
python3 camera/ros2_camera_bridge.py
```

**验证**：`tail -f /tmp/bridge.log`（或桥接进程输出）里的「收到」计数在涨。

> ⚠️ 坑：ascamera 节点「start streaming 后立刻 stop streaming」是**没有订阅者**的正常表现——桥接进程（订阅者）连上后相机才恢复推流。所以先起桥接，或看到 stop 别慌，等桥接起来再看。

## 二、机械臂（从臂）

- 串口：`/dev/serial/by-id/` 下 `...72` = 主臂、`...73` = 从臂（插拔可能互换，以 by-id 为准）
- 客户端 `--port` 默认 `...73`（从臂）
- 标定文件：`robot/my_awesome_follower_arm.json`（从臂）+ `my_awesome_leader_arm.json`（主臂），`install_dependencies.sh` 会拷到 lerobot 缓存目录
- 换算：`FeetechMotorsBus` 用标定 range 完成 归一化 ↔ 0..4095（关节 ±100、夹爪 0..100）
- 夹爪 ID 6 掉线老毛病：报 `Missing motor IDs: 6` 就重新上电

## 三、客户端参数

```bash
conda activate lerobot
python client/wallx_realtime_client.py --help   # 全参数
```

关键参数：

| 参数 | 默认 | 作用 |
|---|---|---|
| `--execute` | 关 | 真发舵机（不传=只打印 dry-run） |
| `--ws-url` | ws://localhost:32195 | 云端 serving（走隧道） |
| `--port` | ...73 by-id | 从臂串口 |
| `--max-delta` | 5.0 | 单步幅度限幅（0=满幅度不限） |
| `--execute-interval` | 0.083 | 每帧节拍秒（12fps 训练帧率；轻柔用 0.15） |
| `--no-grasp-reflex` | reflex开 | 关夹取判定，纯看模型 |
| `--no-bias-correct` | 偏差补偿开 | 关偏差补偿 |
| `--plan-smooth` | 3 | 计划滑动平均窗口（1=关） |
| `--seam-frames` | 3 | 接缝缓动帧数（0=关） |

## 四、安全

- **急停 = Ctrl-C**：立即停止发送，舵机保持当前位姿（不断电）
- dry-run 默认不碰舵机，先 dry-run 再 --execute
- NaN/Inf 保护 + 关节范围钳位 [±100]/[0,100] 始终生效（不随参数关闭）
- 满幅度（`--max-delta 0`）时起步会很快（折叠位→伸过去的首段大位移），人离远、手放 Ctrl-C

## 五、推荐命令

```bash
# 验证全链（不动机器人）
python client/wallx_realtime_client.py

# 轻柔满幅度真机
python client/wallx_realtime_client.py --execute --no-grasp-reflex --max-delta 0 --execute-interval 0.15
```
