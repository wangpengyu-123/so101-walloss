# 云端部署（serving + SSH 隧道）

云端 = AutoDL 实例，跑 wall-x serving，本地客户端通过 SSH 隧道连它。

> 云端 SSH 地址（`<host>:<port>`）是动态的，**从队友处获取**，不要写进仓库。

## 一、serving 启动

合并后的模型放在云端后，起 serving（**必须**带 sdpa，flash_attn 在部署环境会崩）：

```bash
WALLX_VISION_ATTN_IMPLEMENTATION=sdpa \
python -m wall_x._vendor.harrix.serving.launch_serving \
  --env X2ROBOT --host 0.0.0.0 --port 32195 \
  --image-passing-mode base64 --no-serialize-actions \
  model-config:server-model-config \
  --model-config.checkpoint-path <merged_model_dir> \
  --model-config.action-horizon 32 \
  --model-config.robot-type desktop \
  --model-config.robot-action-interpolate-multiplier 1 \
  --model-config.robot-action-end-ratio 1.0 \
  --model-config.model-device cuda \
  --model-config.train-config-path <config_full_v2_round4.yml> \
  --model-config.norm-key so101_table_pick_place
```

要点：
- `--no-serialize-actions`：原样返回 [32,26] 动作（客户端取前 6 维）
- `norm-key so101_table_pick_place`：与训练 `repo_id` 一致
- `action-horizon 32`：与训练 `action_horizon` 一致
- 模型已合并（`merge_v2.py` 产物，843 tensors，含动作头，不能用裸 LoRA checkpoint）

## 二、serving 的 SO-101 注册（已打在 wallx/ 源码里）

wall-oss 预训练是 7 维 EE（`follow_pos`），我们要 6 维关节 `so101_joint_pos`。`wallx/` 源码已打 3 处注册（换干净 wall-x 需重打，见 `patches/patch_serving_so101.py`）：

1. `base_dataclass.py`：`dof_dims` 加 `"so101_joint_pos": 6`；`data` 初始化加 `state_so101_joint_pos`
2. `robot.py`：`get_observation` 加 `so101_joint_pos` 分支（直接保存，跳过 follow_pos 解析）

没打这 3 处会报 `follow_pos expects 7 dims`。

## 三、SSH 隧道（本地）

```bash
ssh -N -f -L 32195:localhost:32195 -o ServerAliveInterval=30 root@<host> -p <port>
```

- `-N -f`：后台、不执行命令
- `-L 32195:localhost:32195`：本地 32195 → 云端 localhost:32195
- 建议在 `~/.ssh/config` 配别名 + ControlMaster 持久连接，避免反复断开

## 四、验证

隧道后，本地连一下确认 serving 响应：

```bash
python -c "
import asyncio, websockets, msgpack
async def t():
    async with websockets.connect('ws://localhost:32195') as ws:
        print(msgpack.unpackb(await ws.recv(), raw=False))
import asyncio; asyncio.run(t())
"
```

看到 `{'batch_enabled': True, 'model': 'wall-x', 'env': 'x2robot'}` 即通。

## 五、开环评估（验证模型，不上真机）

云端跑 `scripts/eval_openloop4.py`（需 serving 已在 32195 监听）：对 60 个数据集样本做开环推理，输出每关节 L1 + bias。

**重点看 `wrist_flex` 的 bias**：round3 曾塌陷 +26.9°，round4 修好后 +8° 左右。若 bias 异常大，先别上真机。
