# 环境搭建

分两部分：**本地真机环境**（跑客户端）和 **云端训练环境**（已就绪，一般不用重新搭）。

## 一、本地真机环境（新电脑）

一键装：`bash install_dependencies.sh`（幂等）。它做的每一件事，手动版如下（排查用）：

### 1. conda + env

```bash
conda create -n lerobot python=3.10 -y
conda activate lerobot
```

### 2. Python 运行依赖

```bash
pip install opencv-python numpy msgpack msgpack-numpy websockets pyyaml pyserial deepdiff tqdm
```

> **不需要 torch**。客户端只 import `lerobot.motors`（串口驱动模块，依赖 pyserial/deepdiff/tqdm），不涉及模型训练。

### 3. lerobot fork（机械臂驱动）

```bash
pip install -e wallx/lerobot --no-deps
```

`--no-deps` 关键：lerobot 的 pyproject 钉了 torch 版本，不传会把环境里可能的 torch 降级；我们只要它的 motors/robots 模块。

### 4. ROS2 humble（相机链需要）

Ubuntu 22.04 专用。官方安装：

```bash
sudo apt update && sudo apt install -y ros-humble-ros-base python3-colcon-common-extensions
```

（ROS2 apt 源配置见 https://docs.ros.org/en/humble/Installation/Ubuntu-Install-Debians.html）

### 5. v4l2loopback（建 /dev/video10）

```bash
sudo apt install -y v4l2loopback-utils
sudo modprobe v4l2loopback video_nr=10 card_label="so101_global" exclusive_caps=1
```

### 6. ascamera SDK 编译

```bash
cd camera
source /opt/ros/humble/setup.bash
colcon build --symlink-install
```

### 7. 机械臂标定文件

```bash
mkdir -p ~/.cache/huggingface/lerobot/calibration/{robots/so101_follower,teleoperators/so101_leader}
cp robot/my_awesome_follower_arm.json ~/.cache/huggingface/lerobot/calibration/robots/so101_follower/
cp robot/my_awesome_leader_arm.json  ~/.cache/huggingface/lerobot/calibration/teleoperators/so101_leader/
```

> 标定文件是**这台机械臂**的物理标定（range_min/range_max）。换机器人要重新 `lerobot-calibrate` 标定，不能复用本仓库的。

## 二、云端训练环境（AutoDL，已就绪）

训练在云端 AutoDL 实例跑，环境已配好（venv `/root/autodl-tmp/wallx_ft/env`，python 3.10.8 + torch 2.10.0+cu128）。

关键点：
- wall-x 源码需带 4 类补丁：LoRA action head + serving `so101_joint_pos` 注册 + flow virtual-tail + sdpa（本仓库 `wallx/` 就是补丁后的完整源码）
- CUDA 扩展安装期编译，需 `MAX_JOBS=8 pip install --no-build-isolation -e wallx/`
- 权重 `wall-oss-0.5` + `Qwen2.5-VL-3B-Instruct` 从 HuggingFace 下载（约 15G，本仓库不含）

云端重建步骤见 [训练流程.md](训练流程.md)。
